# Visual research and text-on-visual planning

For `/codie-geo visuals` or articles/social posts needing art direction, derive visual references from the **specific** topic and brand. Never suggest using copyrighted reference artwork unchanged; visual-search results inspire composition, not permission to reproduce.

Provide these 12 blocks when a detailed visual search is requested:
1. Exact core keywords.
2. Style and aesthetic keywords (specific adjectives, not 'nice/creative/modern' alone).
3. Design-discipline keywords (editorial, infographic, type system, layout, UI, packaging...).
4. Industry-context keywords (users, sector, scenarios).
5. Mood and brand personality keywords.
6. Asset/deliverable keywords (carousel, diagram, explainer, short-video cover, etc.).
7. Long-tail search phrases.
8. Alternative search paths.
9. Negative/exclusion terms.
10. Platform-ready strings for Behance, Dribbble, Pinterest and relevant stock/portfolio tools.
11. Top 15 ranked final keywords.
12. Top 5 ready-to-paste search strings.

For each proposed visual include platform, creative concept, layout/ratio **as a preference subject to up-to-date platform support**, up to ten short text-on-visual headline options when requested, accessible alt-text, the verified fact it illustrates, rights/licensing status, and placement. Do not falsely imply photography/screenshots are actual events. For diagram data, require source numbers.

Default visual ideas for each channel:
- Instagram: original carousel with slide-by-slide educational progression; succinct cover text, readable slide hierarchy and alt text.
- LinkedIn: one insight-rich graphic/document carousel based on actual proof.
- X: a compact chart, screenshot from authorized public docs, or no image if the text is stronger.
- Reddit: visuals only when they answer the community's question and comply with subreddit rules.
- Facebook: accessible native image or short educational sequence with legible text.

Ask the user before sourcing or generating assets when profile requires approval. Image ideas/prompts are not evidence that image files were created.
