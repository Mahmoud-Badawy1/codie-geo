# Codie GEO — every command

Use **`/codie-geo`** to run everything from setup, audit and report to finished, reviewed content.

For a specific website, use `/codie-geo https://example.com`.

## Audit and reporting commands

| Command | What you get |
|---|---|
| `/codie-geo audit <url>` | Full website SEO/GEO audit with five specialist analysis roles |
| `/codie-geo quick <url>` | Rapid, explicitly scoped public GEO/SEO snapshot; untested checks labelled |
| `/codie-geo page <url>` | Detailed assessment for one page |
| `/codie-geo citability <url>` | Analyze passages for answer-engine citation readiness |
| `/codie-geo crawlers <url>` | Check robots.txt and AI crawler access policies |
| `/codie-geo llmstxt <url>` | Analyze or draft llms.txt, explaining its optional status |
| `/codie-geo brands <url>` | Investigate public brand/entity mentions with evidence |
| `/codie-geo platforms <url>` | Per-platform readiness analysis, not invented visibility |
| `/codie-geo schema <url>` | Inspect and generate relevant schema with validation |
| `/codie-geo technical <url>` | Inspect technical SEO, crawl/index signals and speed where measured |
| `/codie-geo content-audit <url>` | Audit existing content quality, E-E-A-T and usefulness |
| `/codie-geo content-quality <url>` | Alias for content-audit, avoiding collision with content creation |
| `/codie-geo report <url>` | Compile a clear client-ready evidence-linked audit report |
| `/codie-geo report-pdf <url>` | Create professional PDF report from measured data and source report |
| `/codie-geo compare` | Compare dated audits with matched scope |
| `/codie-geo proposal` | Proposal grounded in real audit and agreed scope |
| `/codie-geo prospect` | Optional prospect tracker, explicit user approval |
| `/codie-geo content <url>` | Audit existing content quality when URL is provided; without URL write content from a brief |
| `/codie-geo update` | Check availability of upstream security/compatibility updates; never overwrite local work silently |
