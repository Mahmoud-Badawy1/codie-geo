# The unified Codie GEO workflow

`/codie-geo all [website]` defaults to a connected process. Reuse current profile and adapt to the business.

1. **Setup** if profile is missing (minimum: project/site, audience, goal, output location). Save profile if filesystem available.
2. **Install** original audit components if absent, following `bootstrap.py` with network permission. If installation is blocked, distinguish a limited manual audit from a fully integrated one.
3. **Audit** website + AI-answer readiness: original audit engine, findings/evidence, confidence, coverage, source timestamps and a client-ready report. Do not claim unobservable LLM visibility.
4. **Improve**: analyze gaps, perform current research, benchmark relevant peers and build impact/effort prioritized 90-day roadmap and verification KPIs.
5. **Trend research**: fresh, directly relevant topic(s), check history, extract verified claims, choose SEO/AEO/GEO intent; save dated briefs. Never reuse an identical previous topic without a substantial new angle.
6. **Create**: approved article(s) from briefs using `editorial/copywriting.md` and user-provided real evidence; natural storytelling, no invented experience.
7. **Social by default**: Instagram, LinkedIn, X, Reddit and Facebook with channel-native copy, CTA, visual direction and relevant hashtags (Reddit hashtag suggestions separate from post).
8. **QA and deliver**: original audit requirements plus `workflows/qa.md` for article/social/citations/assets and persistence. Deliver audit, plan, research briefs, drafts, native social posts and final QA report.
9. **Compare** only on later runs with real baseline data, not fabricated improvement numbers.

Commands can run independently; `all` is the default end-to-end chain, not a reason to ignore approval requirements. If a new website is not available and the user only provides a topic, skip unavailable site audit with an explicit notice and continue the content workflow.
