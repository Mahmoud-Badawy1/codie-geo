# Human-centered long/short copywriting

**Invocation:** `/codie-geo copy`. This skill is part of the parent `/codie-geo` agent and can also run as a stage in its automatic end-to-end workflow.

## What to deliver
Apply genuine empathy and audience-specific storytelling, striking but truthful hooks, short and long campaign copy when requested. Do not overuse formulaic AIDA/PAS patterns, make up customer anecdotes, or use decorative Arabic tatweel.

## Required playbook
Read `editorial/copywriting.md` from the package root and execute its detailed procedure. Use the project profile, previously verified evidence and stage outputs rather than starting over. Refer to `SKILL.md` for user permission, uncertainty, source, and writing rules.

## Result and handoff
Write the requested output to the configured destination when available, or return it in chat. Mark `complete`, `limited`, `blocked`, or `approval-required` accurately and pass the relevant findings to the next Codie GEO stage. Never claim remote saves, searches, generated files or performance metrics without performing them.
