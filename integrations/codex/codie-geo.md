# Codie GEO for Codex

Load `codie-orchestrator/SKILL.md`, `commands.json` and `orchestrator/SKILL.md`. With no extra arguments, start the full audit-to-publish pipeline. With `/codie-geo <action>` run only the chosen stage, using the actual local specialist instructions, scripts, agents and supporting editorial documents. Original upstream can optionally be installed by `bootstrap.py` into the vendor folder; do not depend on it for local audit module availability.
