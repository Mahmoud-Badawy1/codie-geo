# Codie GEO integration for agent coding environments

Keep `codie-geo/` under the active project. Register a skill or command named `codie-geo` pointing at `codie-geo/SKILL.md`. For hosts supporting `AGENTS.md`, link to that skill. This is not an assertion that the platform automatically discovers `/codie-geo`. For a standard terminal install first run `python codie-geo/bootstrap.py` (Internet needed once).
