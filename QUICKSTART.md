# Codie GEO quick start

1. Extract ZIP, then run `python codie-geo/bootstrap.py` to install the original audit skill source (one-time Internet access).
2. Register `codie-geo/SKILL.md` in your agent; slash command availability depends on your platform.
3. `/codie-geo setup` for your project's audience, goals, website, voice, storage and approvals.
4. `/codie-geo audit https://example.com` for an evidence-based report.
5. `/codie-geo plan` for researched actions and a prioritized 90-day roadmap.
6. `/codie-geo research` for fresh, non-duplicate topic briefs.
7. `/codie-geo all https://example.com` to run audit, report, gap research, plan, trend research, article, Instagram+LinkedIn+X+Reddit+Facebook posts, QA.

Source scripts are copied on installation, NOT recreated. MIT notice remains in `vendor/UPSTREAM_LICENSE.txt` as required. Platform-independent agent instructions and optional host adapters live under `integrations/`. No website updates or publication without authorization.
