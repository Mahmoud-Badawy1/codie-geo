# Quick start

1. Extract the ZIP and give your assistant access to the `codie-geo` folder.
2. Ask it to read `codie-geo/SKILL.md`.
3. Run `/codie-geo https://yourwebsite.com` for the full audit-to-publish flow.
4. Or choose one step: `/codie-geo audit <url>`, `/codie-geo research`, `/codie-geo create`, `/codie-geo qa`.

All local specialist and publishing skills are included in `skills/codie-geo-*/SKILL.md`.
The package does **not** require the old `/geo` command or a one-time download to discover its local modules.
